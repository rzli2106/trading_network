# Quantitative Asset Correlation Network

## Overview
This repository contains an interactive web application designed to visualize the network topology of financial assets. It uses market data and a calculated correlation matrix to renders a mathematical graph where nodes represent individual equities and edge weights represent their statistical correlation. 


## Installation & Usage
To run this application locally on your machine, ensure you have Python installed, and follow these terminal commands:

1. Clone this repository:
   `git clone [https://github.com/rzli2106/trading_network]`
2. Navigate into the project directory:
   `cd trading_networks`
3. Install the required dependencies:
   `pip install -r requirements.txt`
4. Launch the local web server:
   `streamlit run interactive_network.py`
